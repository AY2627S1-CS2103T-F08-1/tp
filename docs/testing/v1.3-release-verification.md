## Known defect

The profile result viewport was capped at 100 px and could not grow with the
window. This was tracked separately in [issue #63](https://github.com/AY2627S1-CS2103T-F08-1/tp/issues/63).
The successful command-flow and persistence results do not imply that this UI
defect was fixed.
